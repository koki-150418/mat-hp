「コピーして貼る」が消える｜AIがExcelへの転記までやる時代の働き方

目次

  1. 「運ぶ」時間がいちばん長い
  2. 実演：チェックリストをExcelに
  3. どんな転記に使える？
  4. Excelの中でAIを使うときの注意
  5. 転記をなくすための準備
  6. まとめ

AIで文章を作れるようになっても、そのあとに残る作業があります。コピーして、ファイルに貼って、保存して、Excelに入力して…。この「運ぶ」作業に、意外と時間を取られていませんか。

MATの第3回勉強会では、AIがExcelへの転記まで行う実演をしました。この記事では、その内容と、医療職が気をつけたいポイントを紹介します。

「運ぶ」時間がいちばん長い

勉強会のスライドでは、これまでのAIの使い方をこう整理しました。

  1. AIに頼む
  2. 文章が返ってくる
  3. 人がコピーする
  4. ファイルに貼る
  5. 保存する
  6. 表に入力する

3〜6の「運ぶ」作業は、時間がかかるのに何も生み出していません。谷口はこう話しています。

「あなたがやることは確認するだけです」

AIが最後まで運ぶようになれば、人に残るのは「これでいい」と決めることだけになります。

実演：チェックリストをExcelに

勉強会では、まずデモ用のマニュアルPDFから、新人用のチェックリストと空のExcelのチェック表を作りました（実演の記事）。続けて、同じ作業の流れの中で、こう頼みました。

チェックリストの項目を行として追加してください

これだけの指示で、AIがExcelのチェック表に項目を書き込み、入力欄まで作ってくれました。谷口もその場で「こうやって自動入力まで作ってくれました」と驚いていました。チェックリストの項目を1つずつExcelに打ち込む作業が、まるごとなくなったのです。

どんな転記に使える？

  • 研修のチェックリスト → Excelの評価表
  • 会議の議事録の宿題 → タスク管理表
  • アンケートの回答 → 集計表
  • 手書きの記録 → 決められたExcelの様式

MATのキャリア講座のスライドでは、救急救命士のメンバーが、手書きの車両日誌を規定のExcelに読み取らせる指示書を作った例も紹介されています。

POINT

患者さんの情報が入ったExcelや記録を、AIに転記させないでください。転記の対象は、個人情報を含まない業務の書類に限りましょう。また、AIが転記した内容は、元の資料と照らし合わせて必ず確認してください。数字の転記ミスは、手作業以上に気づきにくいことがあります。

Excelの中でAIを使うときの注意

AIの中には、Excelの中から直接使える機能（アドイン）を持つものもあります。初期設定講座の資料では、患者情報を含むファイルを開いたまま使わないことを注意点として挙げました。AIがそのファイルの内容を読み取れてしまうからです。

転記をなくすための準備

  1. 作業用フォルダを作る：元の資料と、転記先のExcelのコピーを入れる
  2. 転記先の様式を整える：列の見出しを分かりやすくしておく
  3. 指示を具体的に：「◯◯の項目を、Excelの◯列に1行ずつ」
  4. 確認する：件数と、いくつかの行を元の資料と照合

パソコンの中のファイルを扱うには、AIのアプリ版（ClaudeのCowork、ChatGPTのWorkなど）と、多くの場合は有料プランが必要です（2026年8〜9月時点）。

まとめ

  • コピー・貼り付け・保存・表への入力は、時間がかかるのに何も生まない
  • AIが転記まで行えば、人に残るのは確認と判断
  • 「項目を行として追加して」の一言でExcelに書き込まれた
  • 患者情報のファイルは扱わない。転記結果は必ず照合する

転記の作業は、職場ごとに形がさまざまです。MATでは、メンバーそれぞれの「運ぶ作業をなくした工夫」を共有しています。
