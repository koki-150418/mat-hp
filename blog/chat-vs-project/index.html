チャットとプロジェクトの使い分け｜遊びの友達から、仕事の秘書へ

目次

  1. チャット：その場限りの相談、初めての作業
  2. プロジェクト：毎日使う、形が決まった仕事
  3. おすすめの流れ：チャットで育てて、プロジェクトへ
  4. 「引っ越し」のサイン
  5. 使い分けの例
  6. さらにその先：スキル
  7. まとめ

AIを使い始めると、「チャットとプロジェクト、どっちを使えばいいの？」と迷うことがあります。結論から言うと、両方使います。役割が違うからです。

この記事では、MATの第2回勉強会で紹介した、チャットとプロジェクトの使い分けを紹介します。

チャット：その場限りの相談、初めての作業

普通のチャットは、新しく開くたびにまっさらな状態から始まります。

  • 初めての作業を試すとき
  • その場限りの質問や相談
  • いろいろな頼み方を試してみるとき

勉強会のスライドでは、チャットを「遊び」「友達」にたとえました。気軽に話しかけて、あれこれ試すのに向いています。

プロジェクト：毎日使う、形が決まった仕事

プロジェクトは、役割・様式・ルールを保存しておき、その中で話すだけで毎回その設定が効くしくみです。

  • 毎日・毎回使う仕事
  • 形が決まっている仕事（記録、レポート、議事録など）
  • 誰がやっても同じ品質にしたい仕事

こちらは「仕事」「秘書」のイメージです。谷口は勉強会でこう話しています。

「遊び感覚で使ってたチャットが、いきなりあなたの秘書になります」

おすすめの流れ：チャットで育てて、プロジェクトへ

  1. チャットで試す：まずは普通のチャットで頼んでみる
  2. 会話で育てる：「もっと短く」「各項目3行以内で」と直しながら、成果物を安定させる
  3. プロジェクトに引っ越す：「これプロジェクトにして」と頼み、設定をまとめてもらう
  4. プロジェクトの中で使う：次からはメモを渡すだけ

最初からプロジェクトを作ろうとすると、何を設定すればいいか迷ってしまいます。チャットで「うまくいく頼み方」を見つけてから引っ越すのが、いちばんスムーズです。

「引っ越し」のサイン

勉強会のスライドには、こう書きました。

「毎回コピペしている指示は、プロジェクトに『引っ越す』サイン」

メモ帳に保存したプロンプトを、毎回コピーして貼っていませんか。それはもう、プロジェクトにしていい合図です。判定の基準は「毎回おなじ前提で、中身だけ変わる」仕事かどうかです。

使い分けの例

  • 「来週の勉強会のテーマ、何がいいかな」→ チャット
  • 「毎日の看護記録の下書き」→ プロジェクト
  • 「この論文の要点を教えて」→ チャット
  • 「毎月の委員会の議事録」→ プロジェクト
  • 「患者さんへの説明、こんな言い方でいいかな」→ チャット（定番の説明文ならプロジェクト）

POINT

チャットでもプロジェクトでも、患者さんの個人情報は入れない、出力は必ず確認する、というルールは同じです。プロジェクトにしたから安全、ということではありません。

さらにその先：スキル

MATの勉強会は、チャット（第1回）→プロジェクト（第2回）→スキル（第3回）と進んできました。プロジェクトでは、まだ「何をしてほしいか」の指示は打っています。スキルになると、作業の手順そのものを覚えさせて、呼ぶだけで仕事が終わる状態を目指します。詳しくはAIのスキルとは？の記事へ。

まとめ

  • チャットは「友達」：初めての作業、その場限りの相談
  • プロジェクトは「秘書」：毎日の決まった仕事
  • チャットで育てて、形が決まったらプロジェクトへ引っ越す
  • 毎回コピペしている指示は、引っ越しのサイン

谷口は、プロジェクト化を「これが仕組み化の第一歩です」と表現しています。どの仕事を最初に引っ越すか迷ったら、MATの仲間に相談してみてください。
